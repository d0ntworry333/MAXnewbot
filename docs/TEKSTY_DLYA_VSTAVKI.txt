========== 1. МЕТОДИКА (перед «Целевая аудитория») ==========

Место выполнения работы: ГБОУ «Школа № 1533 «ЛИТ»», г. Москва. Сроки выполнения: октябрь 2025 г. — июнь 2026 г. Оборудование: персональный компьютер (ОС Windows 10/11), смартфон с установленным клиентом мессенджера МАКС для тестирования. Программные средства: язык программирования Python 3.10+, СУБД SQLite, библиотека maxapi для работы с API мессенджера МАКС, python-dotenv для конфигурации, среды разработки PyCharm и Cursor. Методические материалы: рекомендации заказчика-тренера (Яшанькин Д. А.), материалы «The Muscle Ladder», формула расчёта калорий Миффлина — Сан Жеора (1990). Протокол работы: разработка велась поэтапно — прототип в Telegram (октябрь–декабрь 2025), проектирование архитектуры и базы данных (январь–февраль 2026), миграция в МАКС (март 2026), наполнение восьминедельного цикла, чеков и раздела «Достижения» (апрель–май 2026), подготовка материалов к защите (июнь 2026). Схемы и диаграммы — в разделе «Ход работы, проектирование и реализация» и в приложении А.

========== 2. ЦЕЛЬ И ЗАДАЧИ (перед «Пользовательские сценарии») ==========

Задачи работы

Для достижения поставленной цели были сформулированы следующие задачи:
1. Изучить аналоги (личный тренер, онлайн-курсы, Telegram-боты, мобильные приложения) и определить требования к разрабатываемой системе.
2. Спроектировать архитектуру приложения, структуру базы данных и UML-сценарии взаимодействия пользователя с ботом.
3. Реализовать анкетирование пользователя, расчёт суточной нормы калорий (BMR) и индекса массы тела (ИМТ).
4. Реализовать выдачу тренировочного плана, текстовых описаний техники упражнений и учёт самочувствия при подборе нагрузки.
5. Реализовать восьминедельный тренировочный цикл с пятью контрольными чеками.
6. Перенести программный продукт с платформы Telegram на мессенджер МАКС.
7. Провести тестирование и оформить пояснительную записку и приложения к проекту.

========== 3. ВЫВОДЫ (в самый конец раздела) ==========

Описание завершённого продукта

В результате работы создан МАКС-бот «Твой тренер» — программный продукт для сопровождения самостоятельных тренировок в мессенджере МАКС. Продукт реализован на языке Python с использованием SQLite для хранения данных пользователей и журнала тренировок. Бот выполняет следующие функции: первичное и повторное анкетирование с расчётом калорий и ИМТ; выдачу рекомендаций по питанию и восстановлению с учётом цели (дефицит или профицит калорий); формирование тренировки на день с текстовой техникой упражнений; опрос самочувствия и исключение нагрузки на зону при жалобе на боль; сопровождение восьминедельного цикла с пятью контрольными чеками; фиксацию рабочих весов и отображение прогресса в разделе «Достижения». Продукт готов к демонстрации: запускается локально и работает в клиенте мессенджера МАКС. Архитектура построена по слоям (handlers → services → repositories), что обеспечило перенос с Telegram на МАКС без потери бизнес-логики. UML-диаграммы, фрагменты программного кода и скриншоты интерфейса приведены в приложениях к настоящей пояснительной записке.
