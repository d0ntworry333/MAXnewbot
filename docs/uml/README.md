## Нотация UML на диаграммах

| Тип | Как выглядит | Где использовано |
|-----|----------------|------------------|
| Ассоциация | `———` без стрелки | актор ↔ use case; клиент ↔ API |
| Зависимость | `- - - →` пунктир | `..>`, стереотип `<<use>>` |
| Include | `- - - →` + `<<include>>` | обязательный подсценарий |
| Extend | `- - - →` к базе + `<<extend>>` | опциональное расширение |
| Реализация | `- - - ▷` пустой треугольник | `..|>` implements |
| Обобщение | `———▷` | `--|>` наследование слоёв |
| Композиция | `———◆` | `*--` main.py → приложение |
| Поток объектов | `- - - →` | activity → object SQLite |

Подробная легенда: **`notation_legend.svg`**

## Пересобрать SVG из .puml

```bash
py docs/uml/puml_to_svg.py
```

(нужен интернет — используется сервер plantuml.com)

## Редактирование исходников

Файлы `.puml` — править логику диаграммы, затем снова запустить `puml_to_svg.py`.
